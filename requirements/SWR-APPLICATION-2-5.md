---
itemId: SWR-APPLICATION-2-5
itemTitle: Create Application Run with Unique Identifier
itemHasParent: SHR-APPLICATION-2
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall create application runs from valid metadata submissions and shall assign unique run identifiers to each created run. The system shall return the unique run identifier to users upon successful run creation and shall maintain run state for subsequent operations.
