itemHasParent: SHR-DATASET-1

Layer: CLI (command-line interface)

System shall provide dataset discovery capabilities by listing available dataset indices and displaying dataset column information. The system shall show available dataset sources including index names and metadata structure to help users identify relevant datasets and understand data formats before download operations.
