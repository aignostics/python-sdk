itemId: SWR-APPLICATION-13
itemTitle: Download Application Run Results
itemHasParent: SHR-APPLICATION-3
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall allow users to download analysis results from completed application runs to a specified destination directory. Upon successful download completion, the system shall display a confirmation message in the format "Downloaded results of run '[run_id]'" and complete with exit code 0.
