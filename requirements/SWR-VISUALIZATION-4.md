itemTitle: List Running QuPath Processes
itemHasParent: SHR-VISUALIZATION-1
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall list running QuPath processes in JSON output format. When users execute the processes command, the system shall display running QuPath process information including process IDs in JSON format and complete the operation with exit code 0.
