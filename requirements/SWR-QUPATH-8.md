---
itemId: SWR-QUPATH-8
itemTitle: Launch QuPath with Project
itemHasParent: SHR-QUPATH-1
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall launch QuPath application with prepared project files for visualization. After project creation is completed, the system shall launch QuPath with the prepared project and display the notification "QuPath opened successfully with process id '[pid]'" where pid is the actual process identifier of the launched QuPath instance. The system shall complete the launch operation successfully.
