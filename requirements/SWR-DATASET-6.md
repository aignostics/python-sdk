---
itemId: SWR-DATASET-6
itemTitle: Query and Preview Dataset Contents
itemHasParent: SHR-DATASET-1
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: CLI (command-line interface)
---

System shall allow users to query dataset contents and preview download operations before execution. The system shall execute dataset queries with result counting in the format of rows and columns, support dry-run download operations for validation without file transfer, and complete operations with exit code 0 to help users explore and validate datasets before downloading.
