---
itemId: SWR-APPLICATION-14
itemTitle: Display Run Status Information During Download
itemHasParent: SHR-APPLICATION-3
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall display appropriate run status information during download operations for runs in various states. The system shall include status information in download output indicating whether runs are running, completed, canceled, or in other states, and complete download operations with exit code 0.
