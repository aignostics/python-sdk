---
itemId: SWR-APPLICATION-14
itemTitle: Display Running Status During Download
itemHasParent: SHR-APPLICATION-3
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall display run status information when downloading results from application runs that are still in progress. The system shall include status information showing "status: running on plat" in the download output when the no-wait-for-completion option is used and complete with exit code 0.
