---
itemId: SWR-APPLICATION-2-7
itemTitle: Cancel Running Application Runs
itemHasParent: SHR-APPLICATION-2
itemType: Requirement
Requirement type: FUNCTIONAL
Layer: System (backend logic)
---

System shall cancel running application runs when requested by run identifier. The system shall update run status to canceled state, confirm cancellation operation to users, and shall prevent further processing of canceled runs.
